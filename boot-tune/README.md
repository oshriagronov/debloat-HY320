# Sleep Mode

On an HY320 running `UI_Veng.projector.20241225.164550`, select **Settings → Sleep Mode** in Vibe Home to start the projector’s idle screen-off mode. Press the remote’s Power button to return to Vibe. Setup and everyday use require only the remote.

Sleep Mode starts Android TV’s configured screensaver. With the stock screensaver and projector screen-off behavior enabled, the firmware turns off the projection light while Android is in its Dreaming state. Android stays running, and power use may differ from standby. Custom screensaver settings can change the result.

## Upgrading from 0.14.9

Vibe Home 0.14.9 offered a switch that changed the projector’s device-wide Power setting. If you enabled that switch, turn it off in 0.14.9 before upgrading to restore the stock Power off / Restart menu. If you already upgraded, the [0.14.9 guide](https://github.com/oshriagronov/debloat-HY320/blob/c7b3a45e2c16817c8caf3c1528098f554065cba9/boot-tune/README.md#restore-the-power-menu) contains the restore command.
